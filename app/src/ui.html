Preserve aspect ratio

Higher FPS uses NVIDIA AI frame generation. Maximum output: 4096 pixels per side.

Frame generation & encoding

Encoder quality 1–51: lower retains more detail and uses more space. 0 selects automatic quality. 10-bit output preserves finer colour steps; it does not recover missing source detail.

10-bit SDR supports VSR, frame generation and colour controls. Lightweight Upscale, temporal denoising, sharpening and portrait effects use 8-bit SDR and are disabled.

Detail & cleanup

NVIDIA

Temporal denoising uses nearby frames. VSR cleanup and temporal denoising can be combined. Too much sharpening can create halos.
